## 9. Validation

All IDs in this registry are unique. Referential validation is against the
tables in this artifact and the stage expansion in §4. `FROZEN` count is zero.
The exact canonical-ID count is recorded by the validation report and hash
manifest; wildcard/template tokens are not IDs.
