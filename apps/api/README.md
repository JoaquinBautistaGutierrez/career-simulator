# @career-simulator/api

Bootstrap compilable del futuro borde HTTP autoritativo.

- Dependencias permitidas: configuración de desarrollo; application/schemas cuando existan contratos aprobados.
- Dependencias prohibidas: fórmulas duplicadas de engine/scoring y confianza en datos del cliente.
- Estado actual: no inicia servidor, no expone endpoints y no accede a DB.

```bash
pnpm --filter @career-simulator/api lint
pnpm --filter @career-simulator/api typecheck
pnpm --filter @career-simulator/api build
```
